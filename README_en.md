# AsterXu Theme

A Hexo theme with local search, dark mode and responsive article navigation. The installation check uses Hexo 8 and Node.js 26.

From an existing Hexo site, clone this repository into `themes/asterxu` and set `theme: asterxu` in the site's `_config.yml`. Build with `npx hexo generate`. See the [main README](README.md) for overrides and the installation check.
